# Event Observation Sheet

Use this to time a real event **before** the app is introduced. These numbers are the
baseline. Repeat the same observation at pilot events using the app, then compare.

**Rules for observing:** sit somewhere you can see the organizer, don't help or
suggest anything, and note times from one clock (your phone). Ask the organizer's
permission first.

## Baseline metrics

Work these out after the event:

| Metric | How to calculate | Result |
|---|---|---|
| **Turnaround between rounds** | Average of (E − D) across rounds | |
| Pairings-to-start delay | Average of (B − A) | |
| Late finish | Average of (D − C), when positive | |
| Total event length | Event end − event start | |
| Issues per round | Issues logged ÷ rounds | |
| Organizer minutes spent fixing issues | Total of the "minutes to resolve" column | |

"Turnaround between rounds" is the headline number. If the app cuts it, that is a
concrete, measured result for your resume.
